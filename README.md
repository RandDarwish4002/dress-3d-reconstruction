# Dress 3D Reconstruction

AI-based 3D dress reconstruction from a single image.

## Pipeline

Image
→ TripoSR
→ 3D reconstruction
→ Texture baking
→ Real GLB export

## Project structure

- `src/` — Python classes
- `scripts/` — executable scripts
- `input/` — input images
- `output/` — generated 3D assets
- `notebooks/` — experiments
